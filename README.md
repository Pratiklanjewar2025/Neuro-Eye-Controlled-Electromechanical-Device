# 🚀 Overview

**NeuroEye** is an intelligent **Brain-Computer Interface (BCI)** system that enables hands-free control of an electromechanical device using **Electroencephalography (EEG)** and **Electrooculography (EOG)** signals.

The project combines **Artificial Intelligence, Machine Learning, Signal Processing, Embedded Systems, and Biomedical Engineering** to interpret user intentions from brain and eye signals and convert them into real-time control commands.

NeuroEye aims to provide an affordable and intelligent assistive technology solution for individuals with physical disabilities, offering a foundation for future smart wheelchair and rehabilitation systems.

# 🎯 Problem Statement

Traditional control systems require physical interaction, making them inaccessible for many individuals with severe motor disabilities.

NeuroEye solves this challenge by utilizing **EEG** and **EOG** signals to recognize user intent and control an electromechanical device without physical contact.
